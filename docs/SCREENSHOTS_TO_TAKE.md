# Screenshots to Add to GitHub

Take these screenshots after the project is running:

1. **Terraform apply success**
   - Shows infrastructure provisioned as code.

2. **Argo CD dashboard with app synced and healthy**
   - Shows GitOps deployment working.

3. **kubectl get pods -A**
   - Shows nginx, Argo CD and app workloads running.

4. **curl /health output**
   - Shows the deployed application is responding.

5. **GitHub Actions successful workflow**
   - Shows automated validation.
